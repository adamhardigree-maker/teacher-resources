Common Keyboard Shortcuts

Keyboard shortcuts can save time when creating lessons, managing files, navigating CTLS, and working in a web browser. Use the Windows PC or Mac shortcut that matches your device.

Quick Reminder: Windows shortcuts usually use Ctrl. Mac shortcuts usually use Command (⌘).

Before You Begin

Reading the Shortcuts

Hold the first key, then press the next key. For example, Ctrl + C means hold Ctrl and press C. Some shortcuts may vary slightly by browser or application.

Web Browsing

Browser and Tabs

Use these shortcuts to move more quickly between webpages, tabs, and links.

Tabs

Open and Close Tabs

New tab: Ctrl + T / ⌘ + T

Close tab: Ctrl + W / ⌘ + W

Reopen closed tab: Ctrl + Shift + T / ⌘ + Shift + T

Tabs

Move Between Tabs

Next tab: Ctrl + Tab / Control + Tab

Previous tab: Ctrl + Shift + Tab / Control + Shift + Tab

Page Controls

Refresh a Page

Regular refresh: Ctrl + R / ⌘ + R

Hard refresh: Ctrl + Shift + R or Ctrl + F5 / ⌘ + Shift + R

Navigation

Address Bar and Links

Jump to address bar: Ctrl + L / ⌘ + L

Open link in new tab: Ctrl + Click / ⌘ + Click

Display

Zoom

Zoom in: Ctrl + Plus / ⌘ + Plus

Zoom out: Ctrl + Minus / ⌘ + Minus

Reset zoom: Ctrl + 0 / ⌘ + 0

Capture Your Screen

Screenshots

Screenshots are useful for creating directions, documenting an issue, or showing students where to locate a tool.

Windows PC

Windows Screenshot Tools

Capture part of the screen: Windows key + Shift + S

Copy the full screen: PrtScn

Save the full screen: Windows key + PrtScn

Mac

Mac Screenshot Tools

Capture the full screen: Shift + ⌘ + 3

Capture part of the screen: Shift + ⌘ + 4

Open screenshot and recording tools: Shift + ⌘ + 5

Accessibility and Navigation

Keyboard Navigation

These keys work on both Windows and Mac and can make websites and digital tools easier to navigate without a mouse.

Tab

Move to the next link, button, or field.

Shift + Tab

Move to the previous item.

Enter

Open a link or activate a selected control.

Spacebar

Select a checkbox, activate a button, or scroll.

Esc

Close a menu, dialog box, or full-screen view.

Arrow Keys

Move through menus, lists, and text.

Practice Tip

Start With Three

Choose three shortcuts you use often and practice them for a week. Once they become automatic, add a few more.
