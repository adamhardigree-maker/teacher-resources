Grading in CTLS

The CTLS Grading Center is where you will review student submissions, enter scores, provide feedback, manage assessment attempts, and monitor student progress. This guide walks through the tools you will use most often as a CVA teacher.

The Grading Center

All coursework appears as columns in the Grading Center. Think of the screen like a spreadsheet: students run down the rows, while coursework runs across the columns. From here, you can open a student's submission, enter grades and feedback, review assessments, and identify missing work.

Decoding the Grading Center

CTLS uses status icons to show where a student is in the submission process. Knowing these icons makes it much easier to scan the Grading Center quickly.

Submitted

The student submitted work that is ready to be graded.

Submitted – Late

The student submitted work after the due date and it is ready to be graded.

Missing

The due date has passed and the student did not submit work.

In Progress

The student has started the assignment but has not submitted it.

Important Grade Center Columns

Student Information: The first column contains the student's name, CCSD ID number, course name, and Coursework Average.

CVA Student Orientation Quiz: Students must earn 100% on the orientation quiz before they can begin working in the course.

CVA Welcome Call: Enter the grade for the Welcome Conversation here. Enter 100% after the conversation is complete. If you are unable to connect with the student, flag the assignment as Missing.

The Grading and Feedback Panel

Inside the Grading Center, select the cell for the assignment you want to grade. The grading and feedback panel opens on the right side of the screen.

Key Areas of the Panel

  • Assignment and Student: The assignment title and student's name appear at the top.
  • Reset Attempt: Completely deletes the student's current attempt and allows another attempt. Use this only when you are certain the original submission no longer needs to be preserved.
  • Allow Resubmission: Preserves the student's original attempt while allowing another submission.
  • Missing: Select this when work is not submitted by the deadline. CTLS calculates a zero in the course average and marks the assignment as missing.
  • Points Achieved: Enter the student's score.
  • Feedback: Use the text editor to provide written feedback.
  • Record Video / Record Audio: Record feedback directly for the student.
  • Save and Next: Save the current student's grade and feedback and move to the next submission.
  • Finish Student: Save the student's score and feedback.

Grading Submitted Files

When students submit a file for an assignment, you can review it from the file preview screen. Depending on the file type, CTLS may provide annotation tools for inline feedback. You may also be able to download or preview the file and view the plagiarism detection report.

⚠

Important: If you add inline annotations to a submitted file, click the Save icon in the preview window before navigating away from the feedback panel.

Grading Assessments

Many tests and quizzes are automatically graded, but teachers should still review student responses. Constructed-response questions require manual scoring, and fill-in-the-blank responses may need review when spelling or capitalization causes an otherwise correct answer to be marked incorrect.

Items Tab

  • Select the student's assessment in the Grading Center.
  • Select Items to review individual questions.
  • Review time spent and correct/incorrect status for each item.
  • Review the question, correct answer, and student's response.
  • Add item-specific feedback when appropriate.

Assignment Tab

  • Give overall feedback on the assessment.
  • Use Reset Attempt when an attempt must be completely cleared.
  • Use Overwrite Score when a grade needs to be adjusted manually.
  • Enter overall feedback in the text editor.
  • Use Save and Next to move to the next student.

Reset Attempt removes the student's first attempt completely. Do not use it when the original attempt needs to remain part of the student's record.

Troubleshooting Tests and Quizzes

  • Disable pop-up blockers before beginning a test.
  • Allow the assessment to load completely before starting.
  • Do not use the browser Back or Refresh buttons during an assessment.
  • Do not resize the screen while taking a test.
  • Close other programs and unnecessary browser tabs or windows.
  • Use a wired network connection when possible.
  • On wireless networks, reduce use of other wireless devices when possible.

Test Locking: If the CTLS test-locking feature is enabled, the assessment may be submitted and locked if the student navigates away from the testing window for more than three seconds.

Grading and Participating in Discussions

Discussions are graded in the same way as other assignments. Teachers may also participate directly in a discussion from Student Coursework. Select the discussion board, enter your response, and choose Add Comment.

For video responses, use the video recording option in the rich-text editor. This allows teachers and students to record without leaving CTLS.

Quick Scoring

Quick Scoring gives you another way to open the grading and feedback panel. It is especially useful when you want to work with a specific assignment without scrolling through the full Grading Center.

From the Grading Center

Open the menu at the top of an assignment column and select Quick Scoring.

From Student Coursework

Open the three-dot menu next to the assignment name and select Quick Grading.

Overwrite Scores: In Quick Scoring, select the edit icon beside the score to enter an override score when appropriate.

IMAGE: Quick Scoring screenshot

Before You Leave the Grading Screen

  • Confirm that the score is entered correctly.
  • Provide clear feedback when appropriate.
  • Save inline annotations before closing a file preview.
  • Use Allow Resubmission when the original attempt should remain available.
  • Use Reset Attempt only when the original attempt should be erased.
  • Use Save and Next when grading multiple student submissions.
